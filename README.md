# PrepTalk — AI-Powered Interview Preparation

PrepTalk is a full-featured interview preparation platform that uses AI to simulate real interview experiences — so you walk into every interview fully prepared.

---

## Features

### 🎙️ Mock Interviews
Generate a custom mock interview tailored to your **job role**, **tech stack**, and **experience level**. Answer questions by voice or text, and receive instant AI feedback with a score out of 10 for every answer — along with specific tips to improve.

### 🤖 Live AI Interviewer
Have a real, back-and-forth conversation with an AI interviewer. It asks follow-up questions, probes weak answers, and adapts dynamically — just like a real technical interview. Sessions are scored and saved to your history.

### 📄 Resume-Based Interviews
Upload your resume and get interview questions grounded in **your actual experience** — your projects, companies, skills, and tech stack. No generic prompts. Store your resume to your profile so you don't have to re-upload every time.

### 📋 JD Interview Prep
Paste any job description and PrepTalk will:
1. Extract the role, company, seniority, and tech stack using AI
2. Search the web for real interview experiences at that company
3. Generate a curated bank of **15 targeted questions** — each tagged with difficulty, topic, and whether it was sourced from real interview reports

### 💬 Interview Q&A Bank
Browse AI-generated interview questions filtered by **job profile** and **experience level**. Bookmark questions you want to revisit. Get a fresh set every time.

### 🧩 DSA Practice + Built-in IDE
Practice Data Structures & Algorithms problems generated by AI for your chosen **topic** and **difficulty**. Solve them in a built-in VS Code-style editor with **live code execution** — no external tools needed.

### 📊 Progress Analytics
Track your performance across all interview formats over time. See score trends, session history, and which roles or topics you're strongest in.

### 🔖 Bookmarks
Bookmark any question from the Q&A bank or JD Prep to build your personal study list. Access all saved questions in one place.

### 🔥 Streak & Weekly Goal
Stay consistent with a daily practice streak and a customizable weekly session goal. A nudge banner reminds you when you haven't practiced in a while.

### 📧 Weekly Email Digest
Every Monday morning, PrepTalk sends you a personalized weekly digest with:
- Sessions completed that week
- Your average score and improvement vs the previous week
- A breakdown of recent sessions
- A motivational summary

### 🔗 Share Feedback
After completing any mock interview, generate a public shareable link to your feedback report — no login required for viewers.

## Getting Started

### Prerequisites
- Node.js 18+
- A Supabase project
- API keys for Groq, Tavily, and Resend

### Installation

```bash
git clone https://github.com/your-username/preptalk.git
cd preptalk
npm install
```

### Environment Variables

Create a `.env.local` file in the root with the following:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

GROQ_API_KEY=your_groq_api_key
TAVILY_API_KEY=your_tavily_api_key
RESEND_API_KEY=your_resend_api_key

NEXT_PUBLIC_APP_URL=http://localhost:3000
CRON_SECRET=your_cron_secret
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Database Setup

Run the following SQL in your Supabase SQL editor:

```sql
-- Bookmarks table
create table if not exists bookmarks (
  id uuid primary key default gen_random_uuid(),
  email text not null,
  question text not null,
  answer text,
  profile text,
  created_at timestamptz default now()
);

-- Resume columns on profiles
alter table profiles add column if not exists resume_name text;
alter table profiles add column if not exists resume_text text;

-- Share token on interviews
alter table preptalk add column if not exists "shareToken" text unique;
```
